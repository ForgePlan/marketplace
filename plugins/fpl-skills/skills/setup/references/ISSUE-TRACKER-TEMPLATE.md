- GitHub: `gh issue list --state open --label ready-for-agent`

## Standing rules for this tracker

Anything an agent must never do here, in one line each. Defaults worth keeping:

1. Reading notifies nobody and is never optional. Writing reaches the whole team.
2. No comments, no mentions, no assignee or member changes unless the human asked in this session.
3. No deletion. Close instead.
4. Cross-check any count before reporting it — a filter that silently returns a subset looks exactly
   like a quiet board.

## Out-of-scope archive

Rejected ideas live in `.out-of-scope/{topic}.md`. The `triage` skill reads
them before grilling, to avoid re-suggesting things you already declined.

Template entry:

```markdown
# {Topic}

**Date**: YYYY-MM-DD
**Status**: rejected
**Why**: {one paragraph explanation}
**Re-evaluate when**: {condition that would change the answer, or "never"}
```
