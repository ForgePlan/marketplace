# slopocop-design

**Слоп-полицейский для дизайна.** Не даёт интерфейсу выглядеть сгенерированным ИИ. Дизайн-пара к
[`slopocop`](../slopocop) (текст) — та же форма «копа», другая зона.

## Что делает

- **Детект** — ловит шаблонный, «сгенерированный» вид: дефолтные шрифты, штампованный ритм
  hero → 3-фичи → CTA → футер, курсивные заголовки, выдуманные метрики, перерисованный chrome
  браузера/телефона, мобильные провалы — через 58-гейтный slop-test hallmark.
- **Редизайн** — свежая подача, которая выглядит *сделанной*: новый ритм секций, расстановка
  заголовков, голос компонентов — при сохранении роутов, копирайта, бренда и логики.
- **Ревью** — агент `design-cop` по запросу прогоняет slop-test и отдаёт ранжированный список.

## Состав

| Тип | Имя | Назначение |
|-----|-----|-----------|
| Скилл | `hallmark` | Движок анти-ИИ-слопа: slop-test на 58 гейтов, 21 макроструктура, 50 компонентов, audit/redesign/study |
| Скилл | `frontend-design` | Скилл эстетики от Anthropic — осознанное направление, живая типографика |
| Скилл | `design-taste-frontend` | Вкус для лендингов и портфолио — от брифа к нешаблонному интерфейсу |
| Команда | `/design-audit` | Только slop-test (58 гейтов), ранжированный список, без правок |
| Команда | `/design-redesign` | Свежая подача в существующих границах — роуты/копи/логика целы |
| Агент | `design-cop` | Ревьюер дизайна по запросу |

**Без хука** — осознанно. `laws-of-ux` уже подсказывает на правках фронтенда; второй хук дал бы
двойную подсказку на каждый едит `.tsx`/`.vue`. slopocop-design срабатывает на фразы и явные команды.

## Установка (маркетплейс)

```
/plugin marketplace add ForgePlan/marketplace
/plugin install slopocop-design@ForgePlan-marketplace
```

## Использование

Скиллы срабатывают на естественные фразы — «собери лендинг», «переделай дизайн», «почему выглядит
шаблонно». Не подхватились — зови по имени: «прогони hallmark audit».

Явные команды:

- `/design-audit <файл-или-компонент>` — находки слопа, без правок.
- `/design-redesign <файл> [--mood <имя>]` — редизайн в существующих границах.

Чтобы вытащить ДНК понравившегося дизайна (скриншот или URL), используй режим `study` скилла
`hallmark` напрямую.

## Как соотносится с laws-of-ux

Дополняют друг друга, не пересекаются:

- **`laws-of-ux`** — психология юзабилити (Фиттс, Хик, Миллер). *Удобно ли?*
- **`slopocop-design`** — анти-шаблонная эстетика. *Выглядит сделанным или сгенерированным?*

Прогони оба на странице для полного прохода — они отвечают на разные вопросы.

## Чего тут нет

Текстовый слоп → [`slopocop`](../slopocop). GSAP-анимация — отдельная тема (качество движения, не
слоп), сюда не входит.

работу скилла не влияет. Гейты slop-test и каталоги паттернов не менялись.
