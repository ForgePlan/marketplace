# slopocop

**Ясные рабочие ответы и очеловечивание текста.** Palych отвечает за переписку coding-агента,
два humanizer-скилла — за явно заданную прозу на русском и английском. Не дизайн и не очистка кода.

## Что делает

- **Рабочая переписка** — Palych задаёт краткий, технически точный голос, объясняет новые сложные
  термины при первом появлении и различает сделанное и проверенное.
- **Детект** — находит следы ИИ в прозе (хард-баны, засилье длинных тире, уход от «является»,
  ложные диапазоны, правило трёх, подхалимаж, ровный машинный ритм) и считает чистоту 0–100.
- **Очеловечивание** — переписывает гладкий ИИ-текст в живой авторский голос: мнение, неровный ритм,
  конкретика. Факт-замок запрещает выдумывать цифры и ссылки.
- **Контроль** — хук напоминает про аудит после написания прозы, а агент `slop-cop` ревьюит текст по
  запросу.

## Состав

| Тип | Имя | Назначение |
|-----|-----|-----------|
| Скилл | `palych` | Рабочие ответы, вопросы и progress на RU/EN; жанр и подробность документов сохраняются |
| Скилл | `humanizer-ru` | Русский текст: 54 паттерна, HARD BANS, факт-замок, детерминированный сканер `scan.py` (0–100) |
| Скилл | `slop-humanizer` | Английский текст: де-слоп, синтез 5 humanizer-репозиториев |
| Команда | `/slop-audit` | Только детект, без правки. Сам определяет RU/EN, для русского запускает сканер |
| Команда | `/slop-humanize` | Полное очеловечивание. RU→humanizer-ru, EN→slop-humanizer |
| Агент | `slop-cop` | Ревьюер прозы: по хуку и по запросу |
| Хук | Claude `SessionStart` / trusted hooks Codex | Загрузка Palych и сохранение явных on/off, без аудита каждой реплики |
| Хук | `PostToolUse:Write\|Edit\|MultiEdit` | Молчит на коде, подсказывает на `.md`/`.txt`/`.mdx` |
| Расширение | OMP `omp/palych.mjs` | Автозагрузка того же ядра после native-установки плагина |
| Установщик | `scripts/activate.py` | Включение через явно выбранный файл startup-инструкций любого агента |

## Установка (маркетплейс Claude Code)

```
/plugin marketplace add ForgePlan/marketplace
/plugin install slopocop@ForgePlan-marketplace
```

## Использование

### Рабочая переписка

Palych — общий профиль общения, а не стиль только для Claude. Выбери **один**
способ включения ниже. Обнаруженный скилл сам по себе не означает always-on.
Все способы читают или генерируют инструкции из `skills/palych/SKILL.md`.

#### Любой агент со startup-инструкциями

Установи файлы плагина и один раз выполни из потребляющего проекта:

```bash
SLOPOCOP_PLUGIN=/path/to/installed/slopocop
python3 "$SLOPOCOP_PLUGIN/scripts/activate.py" install --instructions ./AGENTS.md
python3 "$SLOPOCOP_PLUGIN/scripts/activate.py" check --instructions ./AGENTS.md
```

Укажи файл, **который реально читает твой агент**: например `AGENTS.md`, существующий
приоритетный `AGENTS.override.md`, `CLAUDE.md`, `GEMINI.md` или другой Markdown-файл
начальных инструкций. Установщик не привязан к этим именам, модели или провайдеру.
POSIX и Python ≥3.9 нужны только для установки. Готовые инструкции не требуют Python,
поиска скилла или хука плагина при работе. Начни новую беседу — просить «загрузи palych»
перед каждым разговором больше не нужно.

Целевой файл обязателен: личные конфиги не ищутся и не меняются автоматически.
Остальной текст и права файла сохраняются; резервные копии — в `.palych-backups/`.
Повторная установка не дублирует блок. Изменённый вручную блок или связанный файл
не перезаписывается: установщик останавливается с ошибкой. После обновления плагина
повтори `install`; `check` обнаруживает устаревший блок. Для отключения в новых беседах:

```bash
python3 "$SLOPOCOP_PLUGIN/scripts/activate.py" uninstall --instructions ./AGENTS.md
```

Удаляется только управляемый блок Palych. «Отключи Палыча» / `Turn off palych`
действует на текущий разговор; общий способ не создаёт native-хранилище режима.
Клиенту, который не читает ни startup-инструкции, ни скиллы, нужна поддерживаемая
им интеграция: копирование папки плагина само по себе не заставляет его загрузить правила.

#### Native-плагин OMP

```bash
omp plugin marketplace add ForgePlan/marketplace
omp plugin install slopocop@forgeplan-marketplace
```

Установленный пакет объявляет `omp.extensions`; расширение загружает Palych
автоматически, без вызова скилла. Чужие системные инструкции сохраняются; аудита
или сетевого запроса на каждую реплику нет. Явный ON/OFF записывается в активную
ветку сессии OMP, а не в личные настройки. Новые сессии начинают с ON. «Отключи
Палыча» / `Turn off palych` и «Включи Палыча» / `Enable palych` переключают текущую ветку.
Записью журнала управляет OMP; API расширения не подтверждает долговременную запись.
Поэтому наличие пути сессии не выдаётся за подтверждённое сохранение на диск.

Для локального checkout: `omp plugin link "$SLOPOCOP_PLUGIN" --scope project`.
В OMP 18.11.1 один `--plugin-dir` обнаруживает Claude-ресурсы, **но не** entrypoint
расширения пакета. Для разового запуска добавь
`--extension "$SLOPOCOP_PLUGIN/omp/palych.mjs"` либо используй startup-инструкции.
`--no-extensions` или отключение расширения препятствуют native-активации.

#### Native-плагин Codex

```bash
codex plugin marketplace add ForgePlan/marketplace
codex plugin add slopocop@forgeplan-marketplace
```

Проверь и разреши хуки плагина через Codex `/hooks`, затем начни новую сессию.
Установка без доверия хуку не подтверждает автозагрузку. Codex-манифест выбирает
`hooks/codex-hooks.json`; адаптер Python и ядро общие с Claude Code, а состояние
отдельное: `~/.local/state/palych/codex/state.json`. При работе нужны POSIX и Python ≥3.9.
В адаптер внесено одно документированное исправление: включённый fork получает
собственную metadata команды переключения, без повторной передачи родительского ядра.
Если доверие хуку или нужные события хоста недоступны, используй startup-инструкции;
обходить проверку доверия не нужно.

#### Native-плагин Claude Code

После установки Palych включается в новой сессии, если хуки исполняются. При работе
нужны POSIX и Python ≥3.9, только стандартная библиотека. `SessionStart` восстанавливает
ядро после сжатия; обычный prompt не загружает его повторно и не меняет режим.
Состояние — в `~/.local/state/palych/claude-code/state.json`.

**Hook-адаптеры Claude/Codex** поддерживают отдельные prompts:

- «Отключи Палыча» / `Turn off palych` — выключить для текущей беседы.
- «Включи Палыча» / `Enable palych` — включить для текущей беседы.
- «Отключи постоянное включение Палыча» / `Disable palych always-on` — выключить по умолчанию для новых бесед.
- «Включи Палыча всегда» / `Enable palych always` — включить по умолчанию для новых бесед.

Явные session overrides сохраняются при смене default. Цитаты и данные задания
режим не меняют. Native-адаптеры не редактируют инструкции/настройки пользователя;
ошибка хука не подтверждает активацию. Команды смены default не являются API
постоянства для OMP или общего способа через файл инструкций.

Не совмещай способы активации, отдельную установку Palych или второй глобальный
блок. Расширение OMP уступает управляемому startup-блоку, если тот уже есть;
Claude/Codex-хуки с таким блоком совмещать не нужно. Portable discovery через
`.agents/skills/palych` остаётся для клиентов, предпочитающих явную загрузку.

### Работа с текстом

Humanizer-правила действуют на заданный текст или запрошенную прозу, а не становятся
постоянным голосом coding-агента. `/slop-audit` и `/slop-humanize` сохраняют свой формат
отчёта и материала; Palych действует на окружающее общение и не сокращает запрошенный
подробный разбор или официальный документ.

Скиллы срабатывают на естественные фразы — «очеловечь», «убери канцелярит», "humanize this",
"de-slop". Не подхватились — зови по имени: «прогони через humanizer-ru».

Явные команды:

- `/slop-audit <файл-или-вставка>` — отчёт детекта, без переписывания.
- `/slop-humanize <файл-или-вставка>` — рерайт. Тон задаётся словом `casual` / `professional`.

## Опционально: русский сканер

У аудита `humanizer-ru` есть детерминированная половина — `scripts/scan.py`. Нужны два pip-пакета:

```
pip install razdel pymorphy3
python3 <плагин>/skills/humanizer-ru/scripts/scan.py черновик.txt
```

Печатает счёт чистоты 0–100, хард-баны с номерами строк, плотность маркеров, ритм предложений и
соотношение существительных к глаголам. При найденных хард-банах выходит с кодом 1 — можно повесить
на pre-commit и не пускать слоп в репозиторий. Без пакетов скилл тоже работает: аудит идёт по
каталогу без машинных метрик.

## Чего тут нет

Дизайн-слоп (шаблонная вёрстка) и GSAP-анимация — вне slopocop, это осознанное разделение. Нужны —
им место в отдельном плагине про дизайн.
