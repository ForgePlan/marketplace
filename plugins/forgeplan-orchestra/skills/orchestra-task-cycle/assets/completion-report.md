---

Заметки по формату:

- Markdown рендерится. Заголовки, списки, таблицы, ссылки, блоки кода — всё работает.
- Упоминания сущностей: `<!task@uid[Название]>`, `<!document@uid[Название]>`,
  `<!member@uid[Имя]>`. Типы: task, project, member, channel, group, document.
- По умолчанию плагин в чаты **не пишет** — отчёт отдаётся пользователю в сессии. Запись в чат
  задачи возможна только там, где оператор явно включил её для рабочего пространства. Каналы,
  группы и личные сообщения — никогда.
- Голое `09:00` в тексте превращается в тайм-чип со сдвигом часового пояса. Экранировать или
  переформулировать.
